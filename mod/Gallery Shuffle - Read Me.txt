GALLERY SHUFFLE
===============

Gallery Shuffle lets you install several art mods at once (paintings, posters, signs, magazines) and
spread their pictures across the Commonwealth by the shares you choose. Set GPG Painting Replacer
Collection to 40% and Signs Re Texture to 30%: 40% of the paintings and 30% of the signs they replace show
their art, and the rest stay vanilla. Every picture frame gets its own pick.

Works with Fallout 4 versions 1.10.163 (old-gen), 1.10.984 (next-gen), 1.11.169 and 1.11.240 with the
same files. Works with Mod Organizer 2 and Vortex.


REQUIREMENTS
------------
1. F4SE for your game version (f4se.silverlock.org).
2. Mod Configuration Menu (Nexus 21497), any version from 1.39 on.
3. Runtime Database (Nexus 108394). The plugin uses it to run on every game version.


INSTALL (both managers)
-----------------------
1. Install the requirements above.
2. Install "Gallery Shuffle" with your mod manager like any other mod (it is a FOMOD, click through it).
   Make sure GalleryShuffle.esl is enabled in your plugin list. The converter is inside the mod at
   Tools\GalleryShuffle\GalleryShuffleConverter.exe.
3. Download the art mods you want to use: replacers, which change the game's own paintings, posters,
   signs, magazines, props or sounds. Standalone art mods, which add new objects of their own through their
   own plugin (buildable posters, new magazines), need no converting: install them as usual and they keep
   working next to Gallery Shuffle. Mods you already installed work too: the converter can find them.
4. Open the converter (see CONVERT below), drop the archives in (or press "Find installed art mods",
   which ticks your enabled mods; untick what you do not want), press Convert. Afterwards you can disable the original art mods you converted.
   A mod that also adds objects of its own through its plugin can stay enabled: where the shares pick
   Vanilla, Gallery Shuffle shows the game's own files, not the mod's.
5. Mod Organizer 2: press F5, enable the new "Gallery Shuffle Packs" mod and put it BELOW Gallery Shuffle.
   Vortex: open Downloads, install "Gallery Shuffle Packs.zip", enable it, let it override Gallery Shuffle.
6. Start the game. Open MCM, Gallery Shuffle, and set each pack's slider (see MENU below). Each pack has
   one slider, on the page with most of its art; its number is the percent of everything the pack replaces
   that shows its art. The game's own art fills whatever the packs leave.
   Changes wait until you apply them: press "Apply all" on the main page, or answer "Apply all" when
   you leave Gallery Shuffle or the menu with changes not applied. After you confirm, the game saves as
   GShufApply, returns to the main menu and loads that save, so every change shows at once (one loading
   screen; the GShufApply save is overwritten each time). "Cancel" when leaving puts every setting back
   to how it was.


CONVERT
-------
Start GalleryShuffleConverter.exe. The quickest way is to add it as a tool in your manager once:
  Mod Organizer 2: the executables list (the gears icon), Add, browse to
    <your instance>\mods\Gallery Shuffle\Tools\GalleryShuffle\GalleryShuffleConverter.exe
  Vortex: Dashboard, Add tool, browse to Data\Tools\GalleryShuffle\GalleryShuffleConverter.exe in your
    game folder after deployment.
You can also double-click the exe directly.

The window finds your Mod Organizer 2 instances and Vortex by itself:
  Deliver packs to   pick the instance (or Vortex, or a folder of your choice). When you start the
                     converter from inside a manager it preselects that manager.
  Fallout 4 folder   filled from the instance; the vanilla pictures come out of your own game archives.
  Art mods           drop archives (.zip, .7z, .rar) or unpacked mod folders into the list, or use the
                     buttons. Every run rebuilds all packs, so list every art mod each time.
  Find installed art mods   lists the mods in the manager you picked that hold something the converter
                     uses: MO2 mod folders (with enabled or disabled) and downloads, Vortex downloads and
                     staging folder. Mods that are enabled in Mod Organizer 2 are ticked for you; untick
                     what you do not want, and tick any other row to add it. A download you already
                     installed is listed once, as its mod folder.
                     Character mods (faces, skin, hair, eyes) are not art mods and are left out.
  Convert            writes the "Gallery Shuffle Packs" mod (or, for Vortex, a zip in its downloads).

Each mod becomes one pack, named after its file (or, for a mod found in Mod Organizer 2, its mod folder).
To give a pack another name, rename the file or the mod before you add it to the converter. Two packs with
the same name show as two sliders with the same label, so rename one of them. A renamed pack counts as a
new pack: its slider starts at 0.
When a mod's installer offers alternative picture sets, they are pooled into that
pack and shuffled together; tick "Give each alternative picture set its own slider" to give each set its own
pack and slider instead.
Loading screens: every pack picture also becomes a loading screen, shared out on the "Loading screens" page
like the art. If you use ALR (Automated Loading Screen Replacer), Gallery Shuffle leaves the loading screens
to it; tick "Also give the pictures to ALR" (ticked by itself when ALR is installed) and the pictures go
into ALR's picture folder as well. ALR has no sliders, so it shows every picture of every pack.
The log in the window and GShuf\convert-report.txt in the output list what was found in each mod.
Each category page has 10 pack slots; the report names any pack that got no slider.
A mod whose items are all in another mod you convert, file for file (a smaller download of the same mod),
is left out, in whatever order you list them; a warning names the mod that already has them.

What the converter recognizes:
  - Main menu replacers: Video\MainMenuLoop.bk2 (still or animated). Each such mod becomes a choice of the
    "MENU ART" entry in the main menu, between SETTINGS and CREW; each press moves to the next choice.
    A pick restarts the main menu with that video; the choice is kept in GShuf\state.json.
  - Pip-Boy replacers: the screen background (textures\AnimObjects\Pipboy\PipBoyScreen_d.dds) and the
    device skin (PipBoy01_d, PipBoy02_d, PipBoyLabels01_d, PipBoyInterior01_d, PipBoyGlow01_d) get their own
    "Pip-Boy" page: one list for the screen background and one for the skin, Vanilla or one pack each.
  - Textures at vanilla art paths (replacer mods): each picture is tied to the vanilla frame it replaces.
  - Any other texture or material over one of the game's own (props, food boxes, bottles, signs): it goes
    on the "Other replacers" page, or on the page of its kind.
  - Models over one of the game's own, and models or names a mod's plugin gives the game's own objects.
    Pip-Boy models follow the Pip-Boy skin list.
  - Textures the game loads by their name rather than through a material: the sky (stars, sun, clouds),
    the Pip-Boy screen effects, world map and perk chart (these follow the Pip-Boy screen list), decals and
    other texture sets.
  - Sound and music files over the game's own: the shares pick whose file each sound plays, and the pick
    stays the same until you change a setting. The main menu theme follows the main menu list instead.
  - Interface files over the game's own.
  - A mod plugin's changes to the game's own material swaps and texture sets.
  - Materials (.bgsm) at vanilla art paths that point at new textures.
  - A gshuf-pack.json in the mod (optional) listing pictures and categories explicitly.
Each replacement shows only on the objects its mod replaces, just as the mod does on its own. Left alone:
a mod's new objects and their pictures (its own plugin shows them) and textures nothing in the game uses.

Command line (for scripts): GalleryShuffleConverter --game "<Fallout 4 folder>" --out "<mods folder>\Gallery Shuffle Packs" <archives...>


MENU
----
  Picture pages    Paintings, Posters, Signage, Magazines and Quest, each shown when a pack's slider sits
                   there. A pack's slider sits on the page with most of its art and sets all of its art:
                   Alternative Magazine Covers at 40 on Magazines shows its art on 40% of its magazines and
                   on 40% of the 4 paintings it also replaces. The slider's help line says what it sets.
                   The sliders are independent: moving one changes no other. Where two packs replace the
                   same object, their numbers split it; under 100 together the rest is the game's own, over
                   100 they are scaled down to 100.
                   Packs whose art on a page is all for Far Harbor or Nuka-World sit under that location's
                   heading, and the rest (packs that replace base-game files) under "Base game".
  Magazine backs   have no slider. A magazine's back shows the version of that back from the pack its
                   cover shows, or the game's own back when that pack has none; a vanilla cover keeps a
                   vanilla back. A pack with only backs gets no slider, so its backs are not used;
                   the converter warns about it.
  Other replacers  packs whose art is mostly props, food, bottles, models, textures the game loads by name,
                   sounds and music. One slider per pack, as on the picture pages. A pack that replaces 2
                   or more kinds of object (the game's folder for them) also gets a "Set by kind of object"
                   switch: when on, it shows one slider per kind for that pack instead of the pack's own
                   slider; art the pack has on other pages keeps following its own slider.
  Pip-Boy page     two lists, screen background and skin: Vanilla or the pack the Pip-Boy wears.
  Loading screens page   one slider per pack with pictures: the percent of loading screens that show one of
                   its pictures (full screen and still; magazine covers on the game's turning magazine).
                   What the sliders leave shows the game's own loading screens.
  Put art on blank canvases   also fills the empty canvases and frames the game places.
  Apply all        applies every change on these pages (see step 6 above). Leaving Gallery Shuffle or the
                   menu with changes not applied asks "Apply all" or "Cancel"; Cancel puts every setting back.
  Shuffle layout   picks a new arrangement with the same shares. The arrangement otherwise stays the same
                   across saves and loads until you apply a change.
  New layout on every load   off by default; when on, every save you load gets a new arrangement.
  Reset all settings   back to defaults: all art vanilla (every pack slider at 0), Pip-Boy screen and skin
                       on Vanilla, blank canvases off, new layout on every load off, layout seed 1,
                       vanilla main menu video.
  When the converter is run again and the packs it writes changed (a mod added or removed, for example),
  every setting goes back to its default by itself, as with Reset all settings, and a message says "the
  art packs changed, settings were reset". Converting the same mods again keeps your settings.


NOTES
-----
  - Pictures inside precombined meshes (almost all placed art) are drawn from data the game builds when
    an area loads, which is why Apply all reloads the save.
  - An item you pick up keeps the look it had in the world in your inventory, and again when you drop it.
  - Uninstall: disable both mods. Items you picked up while they showed a pack's name keep that name,
    like a renamed item; everything else goes back to vanilla.
  - Log file: Documents\My Games\Fallout4\F4SE\GalleryShuffle.log.
